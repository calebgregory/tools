# Work organization

Shared context for this project lives under `~/tools/lemons/_shared/work-org/`.
Read `instructions.md` and `memory/MEMORY.md` there at the start of a session, and
memory detail files when relevant. Apply the task-management guidance in
`output-styles/*.md` there within this project. The project's own `CLAUDE.md`
beside this file describes its environment and task format.
